# Refining & Optimization

**Pattern: SELECTION.** The objective picks the leaf:

| Objective | Leaf |
|---|---|
| Structure drifted from intent; move/dissolve/consolidate at scale | `refactor-alignment/SKILL.md` — stage-gated transmutation playbook |
| System needs manual babysitting to stay healthy | `low-maintenance-design/SKILL.md` — derived-over-authored, auto-discovery |
| System must detect its own breakage and route repairs | `self-healing/SKILL.md` — smoke manifests, auto-task routing, lossless repair |

These compose: red-team findings → self-healing gates; alignment audits →
refactor-alignment campaigns; refactors end by installing self-healing baselines.

Load ceiling: chosen leaf + this router. Announce your selection.
