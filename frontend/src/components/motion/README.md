# motion/

> **Purpose**: Framer Motion animation primitives — reusable motion components for the RescueShip UI.

## File Catalog

| File | Role |
|------|------|
| `AnimatedCounter.tsx` | Scroll-triggered RAF number ticker |
| `AnimatedNumber.tsx` | Indian locale (en-IN) smooth number formatter |
| `BeamsBackground.tsx` | Ambient blurred gradient background surface |
| `MagneticButton.tsx` | Spring-physics cursor-attracted button |
| `MarqueeLogos.tsx` | Infinite looping brand banner |
| `MotionCard.tsx` | Glassmorphism card with hover-lift and spotlight |
| `SectionReveal.tsx` | Scroll-triggered viewport animation wrapper |
| `TabPill.tsx` | Animated sliding tab indicator via `layoutId` |
| `TextReveal.tsx` | Word-by-word scroll-linked opacity reveal |
| `TiltCard.tsx` | 3D perspective mouse-tilt card |

Shared motion presets imported from `../../lib/motion.ts`: `springSnappy`, `springDefault`, `hoverLift`, `fadeUp`, `scaleUp`.
